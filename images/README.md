# Photos folder — images

Is folder me website ki saari photos hain. Photo badalne ke liye:

1. Nayi photo ko **wahi naam** do jo purani photo ka hai
   (jaise `og-image.jpg`, `panorama-360.jpg`, `story.jpg`).
2. Is folder me purani file ko **replace / upload** karo (wahi naam se).
3. Website par nayi photo dikhne lagegi — page ka code chhedne ki zaroorat nahi.

Nayi photo add karni ho to use alag naam se upload karo, phir `index.html`
me uska naam `images/<naya-naam>.jpg` likhna hoga.

| File | Kahan dikhta hai |
|---|---|
| `og-image.jpg` | Home page ki badi hero photo, share wali photo, 360 viewer ki hero view |

Photo ka size 500KB se kam aur format JPG rakhna behtar hai.
