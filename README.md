# TrekLynks360° — Go where you feel alive.

Local-led adventures in Uttarakhand. Explore six Himalayan treks, step inside
an illustrative 360° panorama and plan your next journey with TrekLynks360°.

## Live demo

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages →
Deploy from a branch → `main` / `/ (root)`) and share the Pages link.

## Project structure

- `index.html` — the complete single-page website (treks, 360° panorama,
  story, guides, contact)
- `images/` — all photos used by the website

## Changing photos

Photos live in `images/` and are loaded by file name. To change a photo,
replace the file with the same name (e.g. upload a new `og-image.jpg`).
No code change is needed. See `images/README.md` for the full photo list.
